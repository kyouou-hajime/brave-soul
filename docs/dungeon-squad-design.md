# ダンジョン部隊戦 Ver.0.1 — 採用仕様
2026-10-13

## 決定事項
- 通常の冒険戦闘は既存のまま。ダンジョン内の戦闘だけオウガバトルに着想を得た**陣形＋部隊単位の作戦＋自動戦闘**へ変更する。
- 味方: 主人公＋同行する魂3体（最大4体）。縦3×横3の配置スロット。空きマスあり。
- 敵: 3〜6体を基本とする（試練ボスは専用編成に拡張可）。
- 個別コマンドの手動連打を廃止。作戦: 突撃／均衡／守備／回復重視を切り替えてターンを自動進行。
- 行動順は素早さ。前衛・後衛、物理・魔法、仲間の回復行動で戦術差を作る。
- 勝利時は現行の宝箱・経験値・ゴールド・ボス報酬を維持。敗北時も現在の周回仕様を維持。
- 陣形の事前編集、職業の自動行動ロジック、敵AIの高度化は別段階で検証。

## 実装進捗
- Phase 0: 読みやすさの修正（実ゲームCSS適用）。
- Phase 1: 戦闘の独立コアを dungeon/ogre-squad-v0.1.js として実装。**現行ゲームにはまだ接続していない**。
- Phase 2: 既存 dungeonBattle 状態とマップ移動イベントに接続。3〜6体の敵編成、同行魂データ、コマンドUI、勝敗処理を統合。
- Phase 3: iPad実機で動作確認、戦闘・保存・敗北時の復帰を試験後に段階公開。

## 原則
原作の固有名称や既存ゲームとの混同を避け、BRAVE SOUL固有の世界観と演出にする。既存の通常冒険戦闘は変更しない。
