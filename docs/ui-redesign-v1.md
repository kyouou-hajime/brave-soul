# BRAVE SOUL — UI改修実装仕様書 Ver.1
更新日: 2026-10-13 / コンセプト: DARK RITUAL

## 目的
既存の育成・転職・TRUE MASTER（99/99 → 100/99）・セーブ・戦闘の挙動を保ちながら、iPadで繰り返し操作するゲーム画面をダークファンタジーの儀式盤として再設計する。

## 配色・操作
- 背景 #080D19、奥行き #11182B、パネル #131A2A
- 本文 #E8E3D6、副文字 #9DAABD、金属装飾 #C6AD79
- 魂 #72C9E9、TRUE MASTER #D7ADF7、危険 #C84B4B
- 日本語の本文は可読性優先。タップボタンは40〜44px程度以上。動きを減らす設定に対応。
- 既存のタイトル画像、主人公画像、保存データを勝手に置換しない。

## 実装順
1. P1: 外部CSS ui/dark-ritual-v1.css — 背景、ボタン、フォーカス、パネル装飾、可読性。ロジック変更なし。
2. P2: 主画面の視覚階層 — 日数・職業・ステータス、主人公、6行動、ログ。TRUE熟練度は独立表示。
3. P3: 0.4〜0.9秒以内を基本としたレベルアップ・転職・TRUE MASTER演出。スキップ可能。
4. P4: 44職の紋章・系統別アクセント・職業説明。解放状態を明確に区別。
5. P5: 戦闘3×3編成と魂の間の見た目改善。戦闘ロジックは別作業。

## 安全性
- セーブキーとローカルデータは変更しない。
- パラディンTRUE条件（特訓3・睡眠2）など確定仕様を維持。
- 新CSSは起動HTMLから外すだけで取り消せる構造にする。
- iPad縦横、タップ、スクロール、ロード、100/99表示を実機確認するまではUI全体の合格扱いにしない。
