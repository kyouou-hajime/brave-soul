# BRAVE SOUL：スキル機能の全件監査（2026-10-16）

## 確認対象
既存 `legacy.html` の `JOB_SKILLS` を走査し、**88種類**を確認。
- `eff` 定義：80件
- `battle` 定義：8件
- 両方の効果定義なし：0件

## 検出した不整合
1. スキル装備画面は MAS スキルを選択して `char.equippedSkills` に保存するが、その配列を新しい部隊戦エンジンが参照していない。
2. 新しいボス戦の `BraveDungeonSquad.advance` は ATK/MAG に基づく通常攻撃と簡易回復が中心で、`JOB_SKILLS` の `eff` および `battle` を読まない。
3. 通常冒険の一部戦闘経路は `LEARNABLE_SKILLS` だけを探索し、`JOB_SKILLS` の MAS 装備技を探索しない。
4. 旧ボス戦処理は `sk.battle` を要求するため、`eff` 型の既存スキル多数が反映されない。
5. ダンジョンの手動戦闘も `battle` 方式と `eff` 方式が混在しており、効果未反映の可能性がある。

## 再現銘柄
`ninja_mas` 「五月雨」：`eff:{t:"multi",hits:5,v:0.6,evaBonus:0.20}` と定義されている。
表記は「5連撃（各ATK×0.6）＋このターンの回避率20％上昇」。スクリーンショットでは装備済みだが、新しい部隊戦エンジンにこの効果の参照処理はない。**装備できることと戦闘で発動することは別**。

## 修正方針（未適用）
- 効果スキーマを正規化し、旧 `eff` / 新 `battle` の双方を扱うアダプターを作る。
- `equippedSkills`（最大6件）を通常冒険・ダンジョン・ボス戦の実戦闘に渡す。
- 物理・多段・魔法・回復・バフ・状態異常・特殊系を個別にテストし、ダメージだけの代替では済ませない。
- MP/HPコスト・対象・発動ログ・特殊効果（五月雨の回避率上昇など）まで反映。
- セーブ形式は変えない。TRUEの解放条件をUIに表示しない。
